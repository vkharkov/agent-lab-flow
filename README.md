# Страницы для GitHub Pages

Статические страницы без сборки.

- `index.html` — главная.
- `flow/index.html` — анимация флоу студии: 6 этапов, 4 гейта.
- `squads/index.html` — три команды агентов и передачи между ними.
- `design/index.html` — реальный цикл дизайна: 7 стадий, 58 шагов.
- `am/index.html`, `deal/index.html` — закрытые страницы для клиентов, под паролем. В главную не входят.
- `.github/workflows/pages.yml` — публикация при каждом push в `main`.
- `tools/leak-check.sh` — проверка перед публикацией: внутренние ID, ключи задач, почта, токены и ваши запретные слова из секрета `LEAK_WORDS`.
- `pages-setup.sh` — разовая настройка нового репозитория.

## Новый репозиторий
```bash
./pages-setup.sh <имя-репозитория>
```
Скрипт проверяет страницы, спрашивает подтверждение, создаёт публичный репозиторий и включает Pages.

## Репозиторий уже есть
1. Скопируйте содержимое этой папки в корень репозитория, вместе с `.github/` и `tools/`.
2. Settings → Pages → Source: **GitHub Actions**.
3. `git push`. Вкладка Actions покажет сборку. Если проверка нашла внутренние данные, публикация не пройдёт.

## Как изменить страницу
Данные и движок лежат в одном файле. Этапы, шаги, роли и тексты гейтов записаны в массиве `SC` в начале скрипта. Правьте только его.

Свои запретные слова (домен сервера, имя аккаунта, названия сервисов) задайте секретом репозитория `LEAK_WORDS`, через запятую: Settings → Secrets and variables → Actions. Сами слова в репозиторий не попадают. Локально: `LEAK_WORDS="слово1,слово2" bash tools/leak-check.sh .`

## Закрытая страница под паролем
Страница шифруется на вашем компьютере. В репозиторий попадает только шифр: AES-GCM, ключ из пароля (PBKDF2-SHA-256, 600 000 итераций).
```bash
node tools/lock-page.mjs <открытая-страница.html> deal/index.html
```
Скрипт спрашивает пароль два раза и не печатает его. Пароль не пишите в аргументы, в файлы и в git. Передайте его клиенту отдельно от ссылки.
Перед шифрованием проверьте открытую страницу: `LEAK_WORDS_FILE=tools/leak-words.txt bash tools/leak-check.sh <папка страницы>`.
Новая закрытая папка: добавьте её имя в цикл `for d in …` в `.github/workflows/pages.yml`.
