# Страницы для GitHub Pages

Статические страницы без сборки.

- `index.html` — главная.
- `flow/index.html` — анимация флоу студии: 6 этапов, 4 гейта.
- `history/index.html` — та же анимация по истории задач проекта SmokeLess.
- `.nojekyll` — отключает обработку Jekyll.

## Публикация
1. Создайте публичный репозиторий и положите содержимое этой папки в корень (или в папку `docs/`).
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` (или `/docs`).
3. Через минуту страница откроется по адресу `https://<user>.github.io/<repo>/`.

## Что внутри страницы флоу
Данные и движок лежат в одном файле. Этапы, шаги, роли и тексты гейтов записаны в массиве `SC` в начале скрипта. Чтобы изменить флоу, правьте только его.

Шрифты грузятся с Google Fonts. Без сети страница работает на системных шрифтах.
